# News Hub — implementation plan (2026-09-29)

Spec (approved by Farjad 2026-09-29): Notion → AlphaBoard → "News Hub — spec". Branch `feat/news-hub` off `v2`.

## What the probes showed (2026-09-29)
- Finnhub `/news?category=crypto|general|forex`: no symbol tags (`related` empty); publishers Cointelegraph, CoinDesk, Forexlive.
- Alpha Vantage `NEWS_SENTIMENT`: `tickers=` is AND, so one ticker per call (`CRYPTO:BTC`); per-ticker `ticker_sentiment_score`. 25 calls/day.
- Marketaux free: 3 articles per call, 100 calls/day; entity tags are mostly equities, so it is used as a keyword search.
- RSS: CoinDesk, Cointelegraph, Decrypt feeds return 25–36 items.
→ Symbols are detected from title/summary text (`lib/news/aliases.ts`); real provider tags raise relevance.

## Pieces
1. `prisma`: NewsPublisher, NewsArticle, NewsArticleSymbol, NewsIndexSnapshot, NewsWeightRun, PublisherWeightChange.
2. `lib/news/text.ts` (canonical URL, title key, publisher key, keyword sentiment score), `aliases.ts` + `match.ts` (symbol detection).
3. `lib/news/sources/*`: finnhub, rss, yahoo, alphavantage, marketaux, newsapi, cryptopanic → `RawArticle`. Budgets + rotation in `AppSetting news.providers`.
4. `lib/news/ingest.ts`: fetch due providers → dedupe (URL, then title within 48 h) → upsert publisher/article/links.
5. `lib/news/score.ts` (pure): recency (half-life 6 h crypto, 24 h other), relevance, corroboration (title-cluster Jaccard ≥ 0.5, distinct publishers, 1 + 0.25·(k−1) ≤ 1.5), article weight, index.
6. `lib/news/read.ts`: ranked headlines per symbol from the DB; `getNews()` uses it, live chain as fallback.
7. `lib/news/index.ts` hourly snapshots; `lib/news/evaluate.ts` fills 4 h / 24 h returns from 1H candles (links and snapshots); `lib/news/stats.ts` publisher accuracy.
8. `lib/news/weights.ts`: weekly agent (`aiJson`, feature `news.weights`, admin user), guards (0.1–1.0, ±0.2, n ≥ 20), change log, admin override + revert.
9. `lib/news/job.ts` + worker loop (10 min, `NEWS_DISABLED=1`), retention (articles 90 d, snapshots 180 d).
10. Admin → News page + API; news panel shows publisher and sentiment source; agent context shows sentiment source.

Shadow rule: the index number is never passed to trading agents.
